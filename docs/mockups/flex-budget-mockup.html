Design notes Fixed categories are grouped at the top with a "Fixed" section header. Each has a small lock icon next to the name.

The flex spending card sits between sections, showing one number: what's left for discretionary spending. Uses the green tint background to stand out as a summary without competing with Actuals/Projections.

Flexible section contains everything else — same category rows as today, same order. Income, Savings, Payment appear here regardless of any fixed flag.

When no categories are marked fixed, the entire Fixed section, flex card, and section headers disappear. The view looks exactly like it does today.
Onboarding scenario New user, no budget limits set. "Rent & Utilities" is seeded as fixed.

Flex card uses actual income ($4,849) minus actual rent spending ($1,350) = $3,499 flex pool. No configuration needed — the insight is immediate.
