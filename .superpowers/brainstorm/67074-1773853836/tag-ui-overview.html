Tags — UI Surface Overview

Where tags appear across the app. Click to indicate priority for v1.

1

Edit Transaction Dialog

Tag picker field below Note. Type to search existing tags or create new ones. Multiple tags per transaction. This is the primary way to tag individual transactions.

2

Bulk Tag in "Show All" Table

Select rows → "Tag" action alongside existing "Move to category". Apply one or more tags to all selected transactions at once. Primary workflow for tagging a trip after the fact.

3

Tag Badges on Transaction Rows

Small colored chips on transaction rows in budget view and Show All table. Visible at a glance without opening the edit dialog. Tappable to filter by that tag.

4

Dedicated Tags View (/tags)

New page accessible from nav. Shows all tags with: total spend, transaction count, date range, category breakdown. Tap a tag to see its transactions. Cross-month analysis (vacation spanning Feb→Mar shows combined total).

5

Rule Action: Auto-Tag

Compound rules can apply tags as an action (alongside categorize). "When merchant contains 'Marriott' → tag 'Travel'". Tags added by rules show attribution like categories do.

6

Tag Filter on Show All Table

Filter dropdown on the Show All table to show only transactions with a specific tag. Quick way to see all "Vacation Mar 2026" transactions without leaving the budget page.

7

Tag Filter on Trends View

Filter charts by tag to see spending patterns for tagged groups over time. "Show me my subscription spending trend" or "How did vacation spending compare to my normal month?"

My v1 Recommendation

Ship 1–4 + 6 (edit dialog, bulk tag, row badges, tags view, table filter). Defer 5 (rule action) and 7 (trends filter) to v2 — they're valuable but independent of the core tagging infrastructure.
